## 🔌 Axios Instance + JWT Interceptor

```typescript
// src/api/axios-instance.ts
import axios from 'axios';
import { useAuthStore } from '@/stores/auth-store';

const api = axios.create({
  baseURL: import.meta.env.VITE_API_BASE_URL || 'http://localhost:8080/api',
  timeout: 15000,
  headers: { 'Content-Type': 'application/json' },
});

// Request: attach JWT
api.interceptors.request.use((config) => {
  const token = useAuthStore.getState().token;
  if (token) config.headers.Authorization = 'Bearer ' + token;
  return config;
});

// Response: handle 401
api.interceptors.response.use(
  (res) => res,
  (error) => {
    if (error.response?.status === 401) {
      useAuthStore.getState().logout();
      window.location.href = '/login';
    }
    return Promise.reject(error);
  }
);

export default api;
```

## 🔄 TanStack Query Pattern

```typescript
// src/hooks/use-orders.ts
import { useQuery, useMutation, useQueryClient } from '@tanstack/react-query';
import { orderApi } from '@/api/order.api';
import { toast } from 'sonner';

// Query: Danh sách đơn hàng
export const useOrders = (params: OrderQueryParams) =>
  useQuery({
    queryKey: ['orders', params],
    queryFn: () => orderApi.getAll(params),
  });

// Query: Chi tiết đơn hàng
export const useOrder = (id: number) =>
  useQuery({
    queryKey: ['orders', id],
    queryFn: () => orderApi.getById(id),
    enabled: !!id,
  });

// Mutation: Tạo đơn
export const useCreateOrder = () => {
  const qc = useQueryClient();
  return useMutation({
    mutationFn: orderApi.create,
    onSuccess: () => {
      qc.invalidateQueries({ queryKey: ['orders'] });
      toast.success('Tạo đơn hàng thành công');
    },
    onError: (err: any) => toast.error(err.response?.data?.message || 'Lỗi'),
  });
};

// Mutation: Thanh toán
export const usePayOrder = () => {
  const qc = useQueryClient();
  return useMutation({
    mutationFn: (id: number) => orderApi.pay(id),
    onSuccess: () => {
      qc.invalidateQueries({ queryKey: ['orders'] });
      qc.invalidateQueries({ queryKey: ['dashboard'] });
      toast.success('Thanh toán thành công');
    },
  });
};
```

## 📄 Chi Tiết Từng Page

### 1. Login Page (/login)
- Card centered, logo, username/password inputs, remember me, submit button
- Zod validation, error messages
- Redirect to /dashboard on success

### 2. Register Page (/register)
- Fullname, username, password, confirm password, role select
- Validation + success redirect to /login

### 3. Dashboard Page (/dashboard)
- 4 stat cards: Doanh thu hôm nay, Đơn hôm nay, Tổng bàn, Tổng NL
- Revenue chart (Recharts): 7 ngày gần nhất (revenue, cost, profit)
- Recent orders table (5 rows)
- Recent expenses table (5 rows)

### 4. Menu Pages (/menu, /menu/new, /menu/:id/edit)
- DataTable: code, name, price, actions (edit, delete)
- Search + pagination
- Form: code, name, price, description

### 5. Recipe Pages (/recipes, /recipes/:menuId)
- Step 1: Chọn món ăn (DataTable menu items)
- Step 2: Quản lý công thức (add/remove ingredients, set qty)
- Dynamic form rows

### 6. Ingredient Pages (/ingredients, /ingredients/new, /ingredients/:id/edit)
- DataTable: code, name, category, unit, price, min_stock, supplier
- Category filter dropdown
- Form with all fields

### 7. Inventory Receipt Pages (/inventory/receipts, /inventory/receipts/new)
- DataTable: id, supplier, date, status badge, creator, actions
- Form: supplier, date, note + dynamic rows (ingredient select, qty, unit_price)
- Complete button (confirm dialog)
- Status badge: PENDING(yellow), COMPLETED(green)

### 8. Order Pages (/orders, /orders/new, /orders/:id/edit)
- DataTable: id, table, time, status, items count, total, actions
- Filter by status tabs (All, Open, Served, Paid, Cancel)
- Form: table select, menu item selector (qty inputs), discount, VAT
- Action buttons: Complete, Pay, Cancel (with confirm dialog)
- Inventory warning alerts

### 9. Invoice Page (/orders/:id/invoice)
- Print-friendly layout
- Restaurant header, order info, items table, subtotal, discount, VAT, total
- Print button

### 10. Table Pages (/tables)
- Visual grid: cards showing table number + status (color-coded)
- Status: FREE(green), OCCUPIED(red), RESERVED(yellow)
- CRUD dialog

### 11. Reservation Pages (/reservations, /reservations/new)
- DataTable: customer, table, party size, start/end time, status
- Form: table select, customer name, party size, datetime pickers, status

### 12. QR Management (/qr)
- Grid of table cards with QR codes
- Generate / Clear / Download buttons per table

### 13. Report Pages (/reports/revenue, /reports/stock)
- Revenue: Date range picker, daily table (revenue, cost, expense, profit)
- Click on day → detail modal (order list + items)
- Stock: 3 sections (Critical/Warning/Normal) with badge counts
- Recent issues table

### 14. User Pages (/users, /users/new, /users/:id/edit)
- DataTable: username, fullname, role badge, active toggle
- Form: username, password, fullname, role select, active checkbox

### 15. Expense Pages (/expenses)
- DataTable: type, amount, description, date, creator
- Inline form / dialog for create/edit

### 16. Public Order Page (/public/order?token=xxx)
- No auth, standalone layout
- Table info display
- Menu grid with + / - qty buttons
- Customer name, phone inputs
- Submit button → success page

## 🎨 UI Guidelines

### Color Coding
| Element | Color | Tailwind |
|---|---|---|
| Status: OPEN/PENDING | Amber | bg-amber-100 text-amber-800 |
| Status: SERVED/CONFIRMED | Blue | bg-blue-100 text-blue-800 |
| Status: PAID/COMPLETED | Green | bg-green-100 text-green-800 |
| Status: CANCEL/CANCELLED | Red | bg-red-100 text-red-800 |
| Table: FREE | Green | border-green-500 |
| Table: OCCUPIED | Red | border-red-500 |
| Table: RESERVED | Yellow | border-yellow-500 |
| Stock: Critical | Red | bg-red-50 border-red-200 |
| Stock: Warning | Amber | bg-amber-50 border-amber-200 |
| Stock: Normal | Green | bg-green-50 border-green-200 |

### Responsive Breakpoints
- Mobile: < 768px (sidebar collapsed)
- Tablet: 768px - 1024px
- Desktop: > 1024px (sidebar expanded)

### Animations
- Page transitions: fade-in (150ms)
- Modal: scale-in (200ms)
- Toast: slide-in from top-right
- Table row hover: subtle bg highlight
- Button hover: scale(1.02) + shadow
- Skeleton loading for data fetch
